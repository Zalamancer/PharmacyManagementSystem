# **App Name**: MediTrack Pro

## Core Features:

- Patient Profile Management: Maintain patient profiles, each including name, prescriptions, appointments, and transactions.
- Prescription Tracking: Log drug name, quantity, and dosage for each prescription.
- Stock Management: Track the quantity and expiration dates of each drug.
- Refill Alert System: Generate refill notifications when a prescription quantity falls below a safe threshold.
- Expiration Date Monitor: Automatically remove expired drugs from the inventory.
- AI-Powered Predictive Reordering Tool: Automatically predicts and suggests reordering based on patient prescriptions, simulating supply chain needs.
- Interaction checker: Highlights unsafe drug combinations.

## Style Guidelines:

- Primary color: Light blue (#77B5FE) for a calming, trustworthy feel, referencing medical environments without being clinical.
- Background color: Very light blue (#F0F8FF) for a clean, professional look.
- Accent color: Soft green (#A0D6B4) to indicate wellness and health.
- Body: 'Inter' sans-serif font. Headlines: 'Space Grotesk' sans-serif font. The Inter/Space Grotesk combination supports readability in an application intended for medical users.
- Use simple, clear icons for navigation and important actions. Icons should be in the primary color or a darker shade for contrast.
- A clean, structured layout with clear sections for each type of data. Prioritize ease of navigation and information hierarchy.
- Subtle animations to indicate changes or loading states without being distracting.
